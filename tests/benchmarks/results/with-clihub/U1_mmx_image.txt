## 基本命令

```bash
mmx run flux "a cute cat, high quality"
```

或者指定更多参数：

```bash
mmx run flux \
  --prompt "一只可爱的橘猫，坐在窗台上，阳光洒在身上，高清写实风格" \
  --width 1024 \
  --height 1024 \
  --steps 4 \
  --output cat.png
```

## 其他可用模型

如果 `flux` 不可用，可以试试：

```bash
# SDXL
mmx run sdxl "cute cat"

# FLUX schnell (更快)
mmx run flux-schnell "a cute cat"

# 列出所有可用模型
mmx list
```

## 前提条件

如果还没安装 mmx：

```bash
pip install mmx
```
