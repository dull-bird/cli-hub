`mmx` (midimaxe) 生成图像的基本命令：

```bash
mmx generate "a cute cat" -o cat.png
```

更完整的例子（带参数）：

```bash
# 正方形
mmx generate "a cute fluffy orange tabby cat, photorealistic" -o cat.png --ar 1:1

# 竖屏
mmx generate "一只可爱的猫" -o cat.jpg --ar 9:16
```

常用的几个选项：

| 参数 | 说明 |
|------|------|
| `-o` / `--output` | 输出文件路径 |
| `--ar` | 宽高比，如 `1:1`、`4:3`、`16:9` |
| `--model` | 指定模型（看你的 mmx 支持哪些） |
| `--negative` | 反向 prompt，排除不想要的元素 |

如果不确定 mmx 是否已安装，可以先跑 `mmx --help` 看看。
