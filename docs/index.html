The blind spot那个盲区

Your agent knows git and docker. It does not know the CLI you installed last week, or any tool released after its training cut-off — so it invents flags, picks the wrong tool, or just gives up. cli-hub gives it a small local registry of the tools you actually have. Agent 认得 git、docker，但它不认得你上周刚装的 CLI，也不认得任何训练截止后发布的工具——于是它瞎编参数、猜错工具、或者直接放弃。cli-hub 给它一个本地小注册表，记录你真正拥有的工具。

Two ways it works两种工作方式

Let the agent pull when it needs to — or push the right entry into its context automatically. 让 Agent 需要时主动拉取——或把对应条目在恰当时机自动推送进它的上下文。

PULL · default · every agent

Look it up查一下

Before using a tool, the agent consults the local registry for real subcommands and flags instead of guessing. Not registered yet? It falls back to live --help and learns on the spot.用工具前，Agent 先查本地注册表，拿到真实的子命令和参数，而不是猜。还没注册？退化为现场 --help 当场学。

PUSH · optional · Claude Code

It comes to you主动找上门

Two hooks inject context automatically: on your message, the list of unfamiliar tools you have; before a command runs, that tool's usage. Non-blocking, and only for tools the model doesn't already know.两个 hook 自动注入：你发消息时，注入你装的陌生工具清单；命令执行前，注入该工具用法。非阻塞，且只针对模型不认识的工具。

Built to be general为通用而设计

The registry is the database注册表就是数据库

Zero network at runtime — hooks and lookups only read local JSON.运行时零联网——hook 与查询只读本地 JSON。

Opt-in, never noisy显式标记，绝不吵

A tool only surfaces if you flag it — no flood of system binaries.工具只有你 flag 了才浮现——不会淹没在系统二进制里。

No opinion about you不夹带预设

No hardcoded tool list, no bound search engine. It stores; your agent researches.不预埋工具清单，不绑搜索引擎。它负责存，Agent 负责查。

Defers to official skills让位官方 Skill

If a tool has its own SKILL.md, cli-hub steps aside.工具自带 SKILL.md 时，cli-hub 自动退让。

Quick start快速上手

Register what you have, flag the unfamiliar ones, and (on Claude Code) go automatic.注册已有工具，标记陌生的，然后（在 Claude Code 上）开启自动模式。

# path varies by agent路径随 Agent 而变
S=~/.agents/skills/cli-hub/scripts/cli-registry.py

python3 $S discover        # scan PATH, register what's there扫 PATH，注册已有工具
python3 $S flag mmx         # mark a tool the model doesn't know标记模型不认识的工具
python3 $S non-standard     # preview the discovery manifest预览发现清单

# Claude Code: push modeClaude Code：开启推送模式
python3 ~/.agents/skills/cli-hub/scripts/install-hooks.py
